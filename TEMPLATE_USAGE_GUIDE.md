## Quick Start (3 Steps)

### Step 1: Upload a Syllabus
1. Go to **Streamlit Frontend** → **Upload Syllabus Tab**
2. Upload a PDF file (e.g., course syllabus)
3. Enter course details:
   - Course Name: "High Performance Computing"
   - Course Code: "CS-4501"
   - Instructor: "Dr. Jane Smith"
   - Semester: "7"
4. Click **Upload and Extract**

### Step 2: Generate Lesson Plan
1. Go to **Lesson Plans Tab**
2. Select your course from dropdown
3. Select a module/topic
4. Choose class type:
   - **Theory**: Only classroom instruction
   - **Lab**: Only laboratory work
   - **Mixed**: Both theory and lab components
5. Click **Generate Lesson Plan**

### Step 3: Download
1. Choose your format:
   - **📄 Text**: Quick view/copy to other tools
   - **📘 Word (.docx)**: For editing in Microsoft Word
   - **📕 PDF**: For professional printing/sharing

## What Gets Generated?

Each lesson plan includes:

✅ **Course Information**
- Official template format
- Course metadata (code, instructor, semester, credits)

✅ **Course Structure**
- 4-5 Course Objectives
- 5-6 Course Outcomes (with Bloom's levels K1-K6)
- 3 Program Specific Outcomes (PSOs)

✅ **Mapping & Alignment**
- CO-PO-PSO Articulation Matrix
- PO-WK-SDG Mapping (Sustainable Development Goals)
- Attainment levels and targets

✅ **Lesson Details**
- 30+ hours lesson plan
- Topics and teaching methodologies
- References (textbook, research, web)
- Assessment criteria

✅ **Lab Components** (if applicable)
- List of lab experiments (6-10)
- Experiment objectives
- CO and PO mappings
- Lab assessment criteria

## File Formats

### PDF (.pdf)
- Best for: Professional printing, sharing
- Generated by: reportlab library
- Size: ~7-15 KB
- Use: Direct printing, email sharing, LMS upload

### Word (.docx)
- Best for: Editing, customization
- Generated by: python-docx library
- Size: ~15-25 KB
- Use: Team editing, format customization, comments

### Text (.txt)
- Best for: Quick preview, copying
- Format: Plain ASCII text
- Size: ~20-50 KB
- Use: Quick viewing, copy to other tools

## Supported Course Types

### 1. Theory Courses
```
Content: Lectures, Discussions, Problem-solving
Format: 30-36 hours of classroom instruction
Assessment: Tests, assignments, final exam
Example: "Data Structures", "Database Systems"
```

### 2. Lab Courses
```
Content: Hands-on experiments, practical work
Format: 15-30 hours of lab work
Experiments: 6-10 practical exercises
Assessment: Lab reports, practical exam
Example: "Digital Electronics Lab", "Microprocessor Lab"
```

### 3. Theory + Lab (Mixed)
```
Content: Lectures + Practical exercises
Format: 30 hours theory + 15 hours lab
Features: Both lesson plan AND experiment list
Assessment: Theory + Lab components
Example: "Operating Systems", "Database Lab"
```

## API Reference

### Generate Lesson Plan
```
POST /api/generate-lesson-plan/

Request:
{
  "syllabus_id": "course-uuid",
  "topic": "Parallel Processing Fundamentals",
  "subject_type": "theory" | "lab" | "mixed"
}

Response:
{
  "id": "plan-uuid",
  "syllabus_id": "course-uuid",
  "topic": "Topic Name",
  "subject_type": "theory",
  "course_name": "High Performance Computing",
  "course_code": "CS-4501",
  "generated_at": "2025-01-15T10:30:00.000Z",
  "content": "Full lesson plan text..."
}
```

### Download Lesson Plan
```
GET /api/lesson-plans/{plan_id}/download/?format=pdf|docx|txt

Formats:
- format=pdf    → PDF file (application/pdf)
- format=docx   → Word document (.docx)
- format=txt    → Plain text file

Example:
http://localhost:8000/api/lesson-plans/abc123/download/?format=pdf
```

### List Lesson Plans
```
GET /api/lesson-plans/

Response:
[
  {plan1},
  {plan2},
  ...
]
```

### Get Single Lesson Plan
```
GET /api/lesson-plans/{plan_id}/

Response:
{Single plan object}
```

## Common Tasks

### Generate PDF Lesson Plan via Command Line
```bash
# Generate lesson plan
PLAN_ID=$(curl -s -X POST http://localhost:8000/api/generate-lesson-plan/ \
  -H "Content-Type: application/json" \
  -d '{
    "syllabus_id": "your-uuid",
    "topic": "Course Topic",
    "subject_type": "theory"
  }' | jq -r '.id')

# Download as PDF
curl -o course_lesson_plan.pdf \
  "http://localhost:8000/api/lesson-plans/$PLAN_ID/download/?format=pdf"
```

### Batch Download All Lesson Plans
```bash
# Get all lesson plans
for plan in $(curl -s http://localhost:8000/api/lesson-plans/ | jq -r '.[].id'); do
  curl -o "lesson_plan_$plan.pdf" \
    "http://localhost:8000/api/lesson-plans/$plan/download/?format=pdf"
done
```

### Export to Word and Edit
```bash
# Download as Word
curl -o course_lesson_plan.docx \
  "http://localhost:8000/api/lesson-plans/{plan_id}/download/?format=docx"

# Open in Word (Windows)
start course_lesson_plan.docx

# Open in Word (Mac)
open course_lesson_plan.docx
```

## Troubleshooting

### "Syllabus not found" Error
- **Cause**: Course not uploaded yet
- **Solution**: Go to Upload tab and upload a syllabus first

### "No modules found in this course"
- **Cause**: PDF had no extractable course outcomes
- **Solution**: Ensure syllabus PDF has course outcomes section

### Download button not working
- **Cause**: Browser cache or API timeout
- **Solution**: 
  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Refresh page (F5)
  3. Try API directly: `curl ...download/?format=pdf`

### PDF file is corrupted
- **Cause**: reportlab library issue
- **Solution**: Reinstall: `pip install --upgrade reportlab`

### Word file has strange characters
- **Cause**: Encoding issue with python-docx
- **Solution**: Try exporting as PDF instead, or reinstall: `pip install --upgrade python-docx`

## Tips & Best Practices

1. **Consistent Course Codes**: Use format like "CS-4501" (DEPT-NUMBER)
2. **Clear Topic Names**: Use specific module names, not generic "Module 1"
3. **Theory vs Lab**: Choose correct type first time (affects content)
4. **Save Backups**: Keep downloaded PDFs for audit trail
5. **Use Word for Review**: Share .docx files with faculty for feedback
6. **Archive PDFs**: Keep final PDFs for accreditation records
